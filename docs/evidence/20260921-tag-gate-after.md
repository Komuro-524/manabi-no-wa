## 結論：人の門が効いている証拠

| | 昇格前 | 昇格後 |
|---|---|---|
| タグ status | candidate | official |
| 同じ発言からの抽出件数 | 2件（LLMは正しく検出） | 2件（同じ） |
| 🚪門1の通過 | **0件（全部 `まだ候補` で落ちる）** | **2件とも通過** |

- **入力（文字起こし）もLLMの抽出結果もまったく同一。変わったのは管理者が承認したという1点だけ。**
- これは DESIGN.md §4「タグ格上げの承認: 管理者だけ」と §8-8「AIが `official` にしない」が
  実際にコードで機能していることの直接証拠になる。
- 逆にいうと、管理者が承認するまでは、記録係Aがどれだけ正確にタグを見つけても
  知見カードにも人のタグにも一切反映されない（`user_tags` も0件のまま）＝
  **勝手にタグが増殖しない**ことも同時に示せている。

# evidence — 提出物の証拠を置く場所

Qiita 記事とピッチに貼る素材をここに集める。採点に直結する。

| 軸 | 撮るもの |
|---|---|
| ① セキュリティ | もくもく会で攻撃文を喋って **Firewall が止める画面** ／ A のキーで通知APIを叩いて **弾かれる画面** |
| ② コストパフォーマンス | Request Logs の **モデル別レシート**（A と B で別々に）／「全部を高級モデルで回した場合」との比較 |
| ③ 信頼性・堅牢性 | 処理の途中で殺して **続きから再開する動画** ／ 誤変換トランスクリプトが門1で止まる ／ 同じ会を2回入れて何も増えない |
| ④ 自律性 | 判断ログ「◯回観測して 立てたのは◯回」／ 企ての履歴 |
| ⑤ アイデア | 4層の輪の図 ／ 場を1回立てる手間の内訳 |

> ⚠️ **貼る前に必ず目視すること。**
> スクショに `sk-orca-` で始まるキー・実名・顧客名・社名が写り込んでいないか。

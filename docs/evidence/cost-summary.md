| | 合計費用（3ライブぶん） |
|---|---|
| `orcarouter/auto` 時代 | $0.037454 |
| `orcarouter/manabi-recorder`（Named Router） | $0.000850 |

```
削減率 = (0.037454 - 0.000850) / 0.037454 = 0.97730... ≒ 97.7%
削減倍率 = 0.037454 / 0.000850 ≒ 44.1倍
```

## ② タグ付けエージェント（recorder）: 同じ入力を最上位モデル直指定と比べる

同じライブ（#12, 発言15行）を`--dry`で3回実行した。
`ORCA_MODEL_OVERRIDE`（F13でscripts/recorder.mjsに追加された、`--dry`時だけ使える
モデル直指定スイッチ）で、`scripts/list-models.mjs`から拾った
**入力単価が最も高いモデル**を1本ずつ直接指定した。

| モデル | 実際に解決されたモデル | 費用 | 備考 |
|---|---|---|---|
| `orcarouter/manabi-recorder`（Named Router） | `google/gemini-2.5-flash-lite` | **$0.000436** | この回はルーター内部でも1段フォールバックが発生した（`フォールバック段=1`）。それでもこの価格 |
| `anthropic/claude-fable-5.1`（Anthropicの最上位。$0.0000100/$0.0000500） | 同左 | **$0.084070** | API呼び出し自体は成功したが、JSONとして読めない出力が返り**カード0件**になった（費用は掛かっている） |
| `openai/gpt-5.5-pro`（OpenAIの最上位。$0.0000300/$0.000180） | ─ | **測定不能** | `400 Response input messages must contain the word 'json' in some form to use '***.format' of type 'json_object'`。API側のバリデーションでリクエスト自体が拒否され、課金前に失敗した |

```
Anthropic最上位 ÷ Named Router = 0.084070 / 0.000436 ≒ 192.8倍
```

**OpenAI最上位は倍率を出せなかった。** `response_format: json_object`を使うには
入力に`json`という単語（小文字）が含まれる必要があるという、このモデル（Responses API系）
特有の制約に、既存のシステムプロンプトの書き方が引っかかったため。
プロンプトを直せば通る可能性はあるが、**今回はF9/F10と同じ方針で、比較のためだけに
本番のプロンプトを書き換えることはしなかった**。起きたことをそのまま記録する。

## ③ 場づくりエージェント（organizer）: 同じ判断を最上位モデル直指定と比べる

新規タグ1件（「情報整理」。比較のためだけに興味タグ1件を一時的に追加し、
測定後に削除した）に対する`judge`判断1回ぶんを、同じく`--dry`で2回実行した。

| モデル | 費用 | 判断 |
|---|---|---|
| `orcarouter/manabi-organizer`（Named Router） | **$0.000206** | wait |
| `anthropic/claude-fable-5.1`（Anthropicの最上位） | **$0.023770** | skip |

```
最上位 ÷ Named Router = 0.023770 / 0.000206 ≒ 115.4倍
```

判断結果（wait/skip）自体は違ったが、これはモデルの違いによる評価のブレであり、
どちらも「この材料の薄さでは今は立てない」という結論の範囲内（wait/skipはどちらも
「今回は開かない」という点で一致している）。

> ★ 以前 DESIGN.md / ARTICLE-OUTLINE.md に書いていた「1回 $0.09 → $0.018」は
> 実測ではなく見積もりの数字だった。今回の実測値（$0.023770 → $0.000206、約115倍）に
> 置き換えた。

## ④ OrcaRouterの確定費用との突き合わせ（F7）

出典: `docs/evidence/20260921-054850-cost-reconcile.md` /
`docs/evidence/20260921-055030-cost-reconcile.md`（`scripts/reconcile-costs.mjs`の実行結果）。

各エージェントが記録した「インライン額」（レスポンスヘッダから読んだcost_usd）と、
OrcaRouter側で確定した「確定額」（`GET /v1/generation?id=<id>`の`total_cost`）を
実行ごとに突き合わせた。

| run | agent | インライン額 | 確定額 | 差 |
|---|---|---|---|---|
| #22 | A（recorder） | $0.000086 | $0.000086 | $0.000000 |
| #21 | B（organizer） | $0.002058 | $0.002058 | $0.000000 |
| #20 | C（mirror） | $0.000190 | $0.000190 | $0.000000 |

3体とも**差はすべて$0.000000**。インラインで記録している費用は、OrcaRouter側の確定額と
完全に一致しており、費用の記録に水増しも見落としも無いことが実測で確認できている。

# デモデータ投入（0006_demo_seed.sql）の適用記録

記録日時: 2026-09-21 01:20 JST ごろ

## 何をしたか

`supabase/migrations/0006_demo_seed.sql` を Supabase の Postgres に直接適用した
（`SUPABASE_DB_URL` 経由。SQL Editor に貼るのと同じ内容を、確認のため一度スクリプトから流した）。

内容：
- 架空の社員10人（`auth.users` + `public.users`）。★実在の会社名・人名は一切使っていない
- その社員たちの知見タグ・興味タグ（`user_tags`）21件

## 結果

```
社員: 10
タグ付け: 21
```

`npm run evidence -- --label demo-seed-applied` で確認:

| テーブル | 適用前（before） | 適用後（demo-seed-applied） |
|---|---|---|
| users | 1 | 11 |
| user_tags | 0 | 21 |

## 冪等性の確認

同じマイグレーションをもう一度流しても件数が変わらないことを確認した
（`on conflict ... do nothing` が効いている＝何度流しても社員が増殖しない）。

```
1回目: 社員=10 / タグ付け=21
2回目: 社員=10 / タグ付け=21   ← 変化なし
```
